# ironvibe-site

**Где править сайт (единственная актуальная копия):** всё в **корне репозитория** — `index.html` (редирект по языку), каталоги локалей `ar/`, `de/`, `en/`, …, общие `theme.css`, `images/`, `screenshots/light|dark/`, JS-файлы, `CNAME`. Это же дерево отдаёт GitHub Pages.

**Flutter-приложение** — только в каталоге `Flutter/`; его не смешивать с файлами лендинга выше.
