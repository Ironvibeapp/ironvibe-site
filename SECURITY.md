# Security

IronVibe is designed to keep training data on the device. There is no account system and no backend that stores workouts.

## Report a vulnerability

Email **support@ironvibe.app** with:

- a short description of the issue
- steps to reproduce
- impact (what an attacker could do)

Please do not open a public GitHub issue for security reports until we have had a chance to fix them.

## What we do not want in this repository

- Android signing keys (`.jks` / `.keystore`)
- `key.properties` (keystore passwords)
- crash-symbol files from obfuscated release builds
